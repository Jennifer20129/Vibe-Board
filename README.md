# 📊 VibeBoard

VibeBoard is a responsive social media analytics dashboard built with HTML, CSS and JavaScript.

## Features

- Social media statistics
- Audience growth chart
- Engagement analytics
- Top performing posts
- Audience demographics
- Dark/light mode
- Date filter
- Responsive design
- LocalStorage theme preference

## Built With

- HTML5
- CSS3
- JavaScript
- LocalStorage

- Responsive CSS
